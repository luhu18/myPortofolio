# Personal Portfolio Website
Clone the repository: https://github.com/luhu18/luhu18.git
A modern, responsive personal portfolio website to showcase my skills, projects, and professional information.

## Features

- **Responsive Design:** Fully responsive layout that looks great on all devices, from mobile phones to desktop monitors.
- **Interactive Elements:** Smooth animations, project filtering, and navigation.
- **Modern UI:** Clean and professional design with a focus on user experience.
- **Contact Form:** Integrated contact form for visitors to get in touch.
- **Project Showcase:** Dedicated section to highlight your best work with filtering options.
- **Skills Display:** Visual representation of your technical skills and proficiency levels.

## Technologies Used

- **HTML5:** For structuring the content.
- **CSS3:** For styling, including Flexbox and Grid for layouts, transitions, and animations.
- **JavaScript:** For interactivity and animations.
- **Font Awesome:** For icons.
- **Google Fonts:** For typography.

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/personal-portfolio.git
   ```

2. Navigate to the project folder:
   ```
   cd personal-portfolio
   ```

3. Open the project:
   - Open the `index.html` file in your web browser to view the website locally.
   - Use a code editor like VS Code to make changes to the codebase.

## Customization

### Personal Information
Update your personal information in the HTML file:
- Name, title, and bio in the hero and about sections
- Contact information in the contact section
- Social media links throughout the website

### Projects
Add your own projects to the projects section:
1. Add project images to the root directory or an 'images' folder
2. Update the HTML with your project details
3. Adjust categories as needed for the filtering system

### Skills
Modify the skills section to reflect your own expertise:
1. Update skill categories and names
2. Adjust the progress bars to match your proficiency levels

### Colors and Styling
The color scheme can be changed by editing the CSS variables in the `:root` selector in `styles.css`:
```css
:root {
    --primary-color: #4a6cf7;
    --secondary-color: #6c757d;
    /* other colors... */
}
```
